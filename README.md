# JavaScript Button Project

A small DOM interaction project with a clickable button and RGB color sliders. The button tracks how many times it has been pressed, and the page includes range inputs for practicing interactive UI controls.

## Features

- Click counter button
- RGB range inputs
- DOM updates through JavaScript
- Basic CSS styling

## How To Run

Open `index.html` in a browser.

## Files

```text
index.html
styles.css
script.js
```

## What I Practiced

- Button click handlers
- Updating text content
- Reading range input values
- Connecting HTML controls to JavaScript behavior
